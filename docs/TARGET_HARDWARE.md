# Hardware alvo

- MS-70CDR original azul, firmware 2.10; não CDR+.
- Efeito PhaserZeh, arquivo PhasrZeh.ZDL (oito caracteres), mesmo ID `0x060003B3`.
- Rate 0,05–3 Hz exponencial; Color 4 STG/8 STG/inv 4/inv 8; Level; Depth; Wave Tri/Sine/Step.
- Arte e controles preservados; textos de seletores adicionados.

O proprietário aprovou a aparência e as ondas suaves anteriores, mas relatou problemas em 2–5. A 1.30 remove esses modos e altera o Rate conforme combinado. O Color original foi analisado em um arquivo público, não extraído desse aparelho; as categorias são correspondentes, sem prova de resposta sonora idêntica.

**A 1.30 ainda precisa de teste físico**, inclusive textos, curva de Rate e patches antigos. [Relatos](HARDWARE_TESTS.md), [instalação](INSTALLATION.md), [validação](VALIDATION.md).
